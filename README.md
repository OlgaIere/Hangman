# Hangman Game
## About the Project
Hangman Game is a simple word-guessing game where the player tries to reveal a hidden phrase by selecting letters.
Each incorrect guess adds a part to the gallows, and the game ends when the player either correctly guesses the phrase or runs out of attempts.

## How to Play
The game starts with a hidden phrase, where each letter is represented by a dash (-).
Click on letters to guess the hidden phrase.
Correct guesses will replace dashes with the chosen letter.
Incorrect guesses add parts to the gallows.
Win by guessing the phrase before the hangman is fully drawn.
